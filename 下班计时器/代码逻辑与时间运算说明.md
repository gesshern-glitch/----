# 下班计时器 — 代码逻辑与时间运算说明

## 一、技术架构

| 层 | 文件 | 职责 |
|---|---|---|
| 主进程 (Node.js) | `main.js` | 创建 Electron 窗口（330×525，无边框透明毛玻璃），处理窗口最小化/关闭 IPC，打包后启用自动更新 |
| 预加载脚本 | `preload.js` | 通过 `contextBridge` 安全暴露 `window.winControl`（minimize / close）给渲染进程 |
| 渲染进程 | `renderer.js` | **全部业务逻辑**：计时、打卡、工时计算、补贴、出勤统计、日历 |
| 页面 & 样式 | `index.html` / `styles.css` | UI 结构与毛玻璃视觉风格 |

数据持久化：全部使用 **localStorage**，无需后端。

---

## 二、核心常量

| 常量 | 值 | 含义 |
|---|---|---|
| `TOTAL_MIN` | 555 分钟（9h15m） | 上班到推荐下班的总时长 = 标准工时 + 午休 |
| `LUNCH_MIN` | 90 分钟 | 午休时长 |
| `BASE_MIN` | 465 分钟（7h45m） | 每日标准出勤工时 |
| 午休固定时段 | 12:30 — 14:00 | 只有落在该时段内的在岗时间才被扣除 |

## 三、时间运算详解

### 3.1 推荐下班时间

```
推荐下班时间 = 上班时间 + 9小时15分钟
```

例：09:00 上班 → 推荐下班 18:15。

### 3.2 午休扣除（固定时段法）

午休不是简单减 1.5 小时，而是计算**在岗区间与 12:30-14:00 的实际重叠**：

```
午休重叠 = max(0, min(下班时刻, 14:00) - max(上班时刻, 12:30))
```

几种情况：

| 上班 → 下班 | 在岗时长 | 午休重叠 | 实际工时 |
|---|---|---|---|
| 09:00 → 18:15 | 9h15m | 90 分钟 | 7h45m |
| 09:00 → 12:00 | 3h | 0 分钟 | 3h |
| 13:00 → 18:00 | 5h | 60 分钟 | 4h |
| 12:00 → 15:00 | 3h | 90 分钟（完整覆盖） | 1.5h |

### 3.3 工时 & 加班

```
实际工时 = 在岗时长 - 午休重叠（最多扣 90 分钟）
加班时长 = max(0, 实际工时 - 7小时45分钟)
```

### 3.4 补贴档位

基于**扣除午休后的实际工时**：

| 实际工时 | 补贴金额 |
|---|---|
| > 9 小时 | 30 元 |
| > 10 小时 | 60 元 |
| > 11.5 小时 | 100 元 |

从高到低匹配，取最高档。

### 3.5 补贴目标时刻推算

当已过推荐下班时间，界面切换为倒计时下一个补贴档位。目标时刻的计算需要**反向推算**——因为加班期间也会经过午休时段，所以采用迭代逼近（3 次迭代足够收敛）：

```
目标时刻 = 上班时刻 + 档位工时 + 期间覆盖的午休时间
```

### 3.6 打卡结算

- **手动打卡**：点击「下班打卡」时记录当前时间，同时固化 `workMin`、`overtimeMin`、`subsidy` 快照到 localStorage，后续不再变动。
- **自动结算**：应用启动时 / 每分钟刷新时，扫描所有过往日期——未打卡的自动以 **23:59** 作为下班时间结算并固化。
- **数据隔离**：只统计**当月**记录，非当月记录自动清理。

## 四、出勤统计逻辑

### 4.1 工作日判定

按优先级：
1. 在 `EXTRA_WORKDAYS` 集合中 → **工作日**（调休补班）
2. 在 `HOLIDAYS` 集合中 → **休息日**（法定节假日）
3. 按周一到周五判断 → 工作日；周六日 → 休息日

内置 **2026 年**全年放假调休安排（国办发明电〔2025〕7号）。

### 4.2 出勤天数 & 出勤率

- **只统计已发生的日期**：今天之前 + 今天（需有打卡记录或手动标记）
- 未来工作日**不提前计入**分母，避免出勤率被稀释
- 支持**手动标记**覆盖（鼠标悬停日历选择）：
  - 出勤（1 天）
  - 出勤上半天 / 下半天（0.5 天）
  - 缺勤（计入分母但不计入出勤）
  - 清空（恢复自动判定）

```
出勤率 = 已出勤天数 / 已过且已确定的工作日天数 × 100%
```

> 出勤率 > 90% 显示红色，≤ 90% 显示蓝色。

### 4.3 日均加班

```
日均加班 = 当月累计加班分钟数 / 实际出勤天数
```

### 4.4 累计补贴

当月所有打卡记录的补贴金额之和（含当天实时补贴）。

## 五、定时刷新机制

| 定时器 | 间隔 | 作用 |
|---|---|---|
| `setInterval(tick, 1000)` | 1 秒 | 刷新倒计时、工时、加班、补贴、闪烁状态 |
| `setInterval(..., 60000)` | 1 分钟 | 自动结算过期记录 + 刷新统计（跨天自动切换） |

---

## 六、闪烁提醒

到达推荐下班时间后，整个卡片以白色高亮动画闪烁（0.9s 周期），顶部显示「到点啦！可以下班了」横幅。用户可点击「停止闪烁」手动关闭，本次运行内不会再次触发。

---

## 七、数据存储结构

| localStorage Key | 内容 |
|---|---|
| `workday-YYYY-MM-DD` | `{"start":"09:00","end":"18:30","workMin":465,"overtimeMin":0,"subsidy":0}` |
| `attendance-overrides` | `{"2026-09-01":"present","2026-09-02":"present-am",...}` |

- 当日未打卡时 `end` 为 `null`，无固化字段。
- 打卡/自动结算后写入 `workMin`、`overtimeMin`、`subsidy` 快照。
